Bomb Manual

The defuser can see the bomb. You can't. Ask questions, then use the rules in this book. Always use the first rule that matches.

Every bomb has 6 modules: 2 Easy (left column), 2 Medium (middle column), 1 Hard (top right) and 1 Grief (bottom right). The bomb picture never shows difficulty names, only this manual does. Not every module in the book is on every bomb, and the defuser will tell you what they see.

You have 6:00 and 3 strikes. The clock freezes while the defuser is thinking. Pick a module above to see its rules, and tap My notes at the bottom to write things down or use the calculator.

Shortcuts: press ? to see them all.

WiresEasy

Count the wires, then use the matching rules. Count from the top, 1 = top.

3 wires

  1. No red wire: cut the 2nd wire.
  2. Last wire is white: cut the last wire.
  3. More than one blue: cut the last blue wire.
  4. Otherwise: cut the last wire.

4 wires

  1. More than one red AND serial's last digit is odd: cut the last red wire.
  2. Last wire is yellow AND no red: cut the 1st wire.
  3. Exactly one blue: cut the 1st wire.
  4. More than one yellow: cut the last wire.
  5. Otherwise: cut the 2nd wire.

5 wires

  1. Last wire is black AND serial's last digit is odd: cut the 4th wire.
  2. Exactly one red AND more than one yellow: cut the 1st wire.
  3. No black wires: cut the 2nd wire.
  4. Otherwise: cut the 1st wire.

Answers panelEasy

The panel shows 4 numbered AI answers. One of them is a hallucination (the AI made it up). Ask the defuser to read every answer: the statement, the source and how sure it sounds. Then go through these rules in order. The first rule that matches an answer tells you which one to flag.

  1. The source is none AND it says 100% sure.
  2. The statement has an exact decimal number (like 91.372%) AND the source is a friend.
  3. The statement says always or never AND the source is a friend, none or a blog.
  4. It says not sure AND the statement has an exact decimal number.

Only one answer matches the first rule that matches anything. Tell the defuser to flag its number.

Example

1: "Accuracy was about 91%" (paper, fairly sure). 2: "Overfitting never happens" (blog, 100% sure). 3: "Recall is exactly 0.83917" (friend, not sure). 4: "A CSV is plain text" (textbook, 100% sure).
Rule 1: nobody has source none. Rule 2: answer 3 has an exact decimal AND a friend, so flag answer 3. (Answer 2 only fits rule 3, which comes later.)

Code panelMedium

The panel shows a dictionary called book: a list of words (keys), each with a number (value). It also has a number keypad. Ask the defuser to read the dictionary out, then run this program in your head and tell them which number to enter:

key = sorted(book)[0]
n = book[key]
if n % 2 == 0:
    answer = n * 3
else:
    answer = n + len(book)

Enter answer on the keypad.

Example

book = {"fox": 4, "ant": 7, "gnu": 2, "cat": 5}
Sorted keys: ant, cat, fox, gnu, so key is "ant". n = 7, which is odd. len(book) is 4, so answer = 7 + 4 = 11.

New to Python?

  • book["ant"] looks up the value for the key "ant".
  • sorted(book) puts the keys in alphabetical order.
  • [0] means the first item. Python starts counting at 0!
  • n % 2 == 0 means n is even (nothing left over when divided by 2).
  • len(book) is how many entries the dictionary has.
  • * means multiply, and + means add.

Scorecard panelMedium

The panel names a scenario, shows four counts and has four buttons A to D. Each button shows a fraction. Press the button whose fraction is the right metric for the scenario.

The four counts

  • TP (true positive): the model said "yes" and was right.
  • FP (false positive): the model said "yes" but was wrong (a false alarm).
  • FN (false negative): the model said "no" but should have said "yes" (a miss).
  • TN (true negative): the model said "no" and was right.

Formulas (write them as fractions, do not simplify)

MetricFractionUse it for
PrecisionTP / (TP + FP)Spam filter
RecallTP / (TP + FN)Cancer screening
Accuracy(TP + TN) / (TP + FP + FN + TN)Quiz marking
SpecificityTN / (TN + FP)Letting honest buyers pass

Example

Spam filter with TP = 12, FP = 3, FN = 5, TN = 30. A spam filter uses precision: TP / (TP + FP) = 12/15. Press the button that says 12/15.

Circuit panelHard

The panel has 4 switches (A to D), three logic gates, an LED and a TEST button. The top gate takes A and B, the bottom gate takes C and D, and the final gate takes the two gate results. Some wires have a small bubble: a bubble flips that input (0 becomes 1, 1 becomes 0) before it enters its gate. Make the LED light up, then tell the defuser to press TEST. Flipping a switch is safe. A wrong TEST is a strike.

Example

Switches A = 1, B = 0, C = 1, D = 1. Bubbles on B and D. Gates: top AND, bottom XOR, final NOR.
After the bubbles: B becomes 1 and D becomes 0. Top: AND(1, 1) = 1. Bottom: XOR(1, 0) = 1. Final: NOR(1, 1) = 0, so the LED is off.
To light it, both gate results must be 0. Flip A to 0: top = AND(0, 1) = 0. Flip D to 0 (it becomes 1 after the bubble): bottom = XOR(1, 1) = 0. Final: NOR(0, 0) = 1. LED on, press TEST!

Neuron panelHard

The panel shows a tiny neural network: 3 inputs (x1, x2, x3), two hidden neurons (h1 and h2, each with 3 weights and a bias) and an output neuron (2 weights and a bias). Ask the defuser to read everything out, then calculate the final output and tell them to enter it.

  1. For each hidden neuron: z = (w1 × x1) + (w2 × x2) + (w3 × x3) + bias.
  2. ReLU: if z is negative, the neuron's result h is 0. Otherwise h = z.
  3. Output = (v1 × h1) + (v2 × h2) + the output bias. Enter this number (it can be negative).

Example

x = (1, 2, 0). h1 has weights (2, −1, 3) and bias −1: z = 2 − 2 + 0 − 1 = −1, so ReLU gives h1 = 0. h2 has weights (1, 1, −2) and bias 1: z = 1 + 2 + 0 + 1 = 4, so h2 = 4. Output weights (3, 2) and bias −2: 3 × 0 + 2 × 4 − 2 = 6.

Use the calculator in your notes. Watch the minus signs!

Map panelHard

The panel is a 10 by 10 grid (x and y from 0 to 9) with 8 numbered coloured points and one mystery point (?). It has three buttons: red, blue, green. This is the K-Nearest Neighbours method with k = 3.

  1. Ask for every point as (x, y, colour), plus the mystery point.
  2. For each point, find its distance to the mystery point: |x difference| + |y difference| (ignore minus signs).
  3. Take the 3 closest points.
  4. Press the colour that appears at least twice among those 3. If all 3 are different colours, press the colour of the closest one.

Example

Mystery point (4, 4). Points: (3, 4) red, (4, 7) blue, (8, 3) green, (2, 2) red, (9, 9) blue.
Distances: 1, 3, 5, 4, 10. The 3 closest are (3, 4) red, (4, 7) blue and (2, 2) red. Red appears twice, so press red.

Learning panelGrief

The panel shows a ball rolling down a loss curve. Gradient descent moves the ball w toward the valley t in small steps. The panel shows w, t, a, the learning rate (lr), the number of steps and a constant c. The loss is a × (w − t)² + c. There are 2 rounds, and the numbers change after a correct answer.

  1. Gradient = 2 × a × (w − t).
  2. One step: new w = w − lr × gradient.
  3. Repeat for the number of steps, using the new w each time (the gradient changes every step).
  4. Enter the final w. Decimals are fine: round to 2 decimal places.

Example

w = 11, t = 3, a = 1, lr = 0.25, steps = 2, c = 5.
Step 1: gradient = 2 × 1 × (11 − 3) = 16, so w = 11 − 0.25 × 16 = 7.
Step 2: gradient = 2 × 1 × (7 − 3) = 8, so w = 7 − 0.25 × 8 = 5. Enter 5.

The constant c never changes the gradient, so ignore it. Use the calculator!

Pattern panelGrief

The panel shows a number from 0 to 15 and five buttons: A, B, C, D, E. Find the right letter 3 times in a row. The number changes after each correct press.

  1. Turn the number into binary: add up the values 8, 4, 2 and 1 (use each one at most once). Example: 11 = 8 + 2 + 1.
  2. Each oval has its own dash pattern, worth 1, 2, 4 or 8 (see the key under the diagram). The number is inside the ovals whose values you used, and outside the others.
  3. Find the area that is inside exactly those ovals. Press the letter in it. For 0, use the letter in the top-left corner (outside every oval).

Example

The display shows 5. 5 = 4 + 1, so it is inside the oval worth 4 and the oval worth 1, and outside the other two. Find that area and press its letter.

The letters in the diagram change every run, so don't memorise them!
